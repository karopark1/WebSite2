# Children's Hope Care

Static website for Children's Hope Care in Mityana District, Uganda.

## GitHub Pages

Upload **all files and the complete `assets` folder** to the root of the repository. Then open:

`Settings → Pages → Deploy from a branch → main → /(root) → Save`

Required structure:

```text
index.html
styles.css
script.js
.nojekyll
README.md
assets/
  organisation-logo.jpeg
  balanja-mark.jpg
  children-home.jpg
  children-courtyard.jpg
  children-watermelon.jpg
  balanja-food-support.jpg
  cbo-certificate.jpg
```
